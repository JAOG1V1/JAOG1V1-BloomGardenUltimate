# 📸 Pasta de imagens (assets)

Coloque aqui as imagens usadas no `README.md` (capturas de tela e GIFs do jogo).

## Arquivos esperados pelo README

O `README.md` referencia os seguintes arquivos nesta pasta:

| Arquivo | Conteúdo sugerido |
|---|---|
| `screenshot.png` | Captura de tela do jardim de dia (visão geral). |
| `screenshot-night.png` | Captura de tela à noite, com vagalumes e estrelas. |
| `gameplay.gif` | GIF curto mostrando a interação com a flor e o jardim reagindo. |

## Como gerar

1. Rode o jogo localmente (`npm run dev`) ou abra a
   [versão publicada](https://JAOG1V1.github.io/JAOG1V1-BloomGardenUltimate/).
2. Use o **Modo Foto** (botão 📷) para esconder o HUD em capturas mais limpas.
3. Salve as imagens nesta pasta com exatamente os nomes acima — assim elas
   aparecem automaticamente no README.

> Dica: mantenha os arquivos leves (PNG otimizado / GIF curto) para não pesar o
> repositório. Esta pasta **não** faz parte do build do Vite; serve apenas para a
> documentação no GitHub.
